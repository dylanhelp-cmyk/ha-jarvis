# HA Jarvis

Local wireless audio test bench for Home Assistant Voice PE and WiiM. Conversational voice is the next milestone after acoustic testing.

[Add this App repository to Home Assistant](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fdylanhelp-cmyk%2Fha-jarvis)

[Install, update and run the first test](INSTALL.md). App updates appear in Home Assistant; firmware source updates are fetched by ESPHome Builder. You choose when to install or flash. Credentials stay local.
